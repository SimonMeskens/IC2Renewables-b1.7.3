# IC2 Renewables Mod for b1.7.3

This is an addon for IC2 for Beta 1.7.3.

- Changed cobble maceration to return gravel instead of sand
- Added extraction recipe to turn gravel into sand
- Added dirt recipe from plantball, 4 sand, and 4 gravel
- Added clay recipe from water cell and 4 dirt
- Added UU recipes for soul sand and glowstone
